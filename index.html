About

At Digit Gate IT, I went from Web Developer to Assistant Software Development Manager in under four years, and today lead the software department as Tech Lead. I lead a team of 12 across 20+ web and 5+ mobile applications, run requirement analysis with clients, design system architecture for web and mobile projects, and manage our AWS infrastructure. I still write code when it matters.

I'm a B-TopSE Certified Trainer in Software Architecture, through a program supervised by TopSE at the National Institute of Informatics (NII), Japan. Good architecture is what separates software that lasts from software that breaks, and helping developers think that way is the part of my work I enjoy most.

Through msilabs, my open-source brand, I build and maintain bKash payment packages for Laravel and Node.js. I'm also co-founder of two software companies, Ihsan IT and Orbeetal, each run by its own dedicated team.

How I work with AI: I use AI-assisted tools for coding, debugging and refactoring, and I review and validate everything they produce before it ships.

Currently learning: NestJS and building AI-powered applications.
